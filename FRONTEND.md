# Интерфейс карты ЛПР

Основной интерфейс: `/`, файлы `frontend/index.html` и `frontend/ui-assets/`. Подключается к существующему FastAPI `/api/v1` с X-API-Key; серверная база, AI, MCP и Docker не заменяются. Предыдущий интерфейс vvv3 сохранён по `/legacy.html`. Оригинальные шрифты Mulish используются из `frontend/assets/`. Для запуска — существующая инструкция README. Для теста — GitHub Actions UI screenshots and interaction. Источник интерфейса: Velight/- PR #1 и #2, merge 88219420e1916d339d8b43abfeee426db50d7324. Резервный локальный демо-адаптер не перенесён.

## Источники и настройки

Шесть экранов по SVG: обзор источников, CRM, почта, календарь, документы и настройки. Данные читаются из существующего API с правами текущего пользователя. Почта и календарь показывают только сохранённые взаимодействия; документы — сохранённые источники. Внешние коннекторы не подключены. Переключатели инструментов управляют только локальным интерфейсом, не серверными правами MCP. Подтверждение правок обязательно; остальные настройки сохраняются в браузере. Старый список источников клиента доступен из нового обзора при открытой карте.
