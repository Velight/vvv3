# КРОК — карта контактов, локальный ассистент и MCP

Полный проект: FastAPI + SQLite, HTML/CSS/JavaScript, локальные SVG/шрифты, Llama через Ollama и MCP. Отдельная сборка фронтенда и Node-сервер не нужны. Исходный интерфейс перенесён из доступных фреймов «экран» Figma 23 53; не все альтернативные фреймы удалось получить из-за лимита Figma.

## Запуск на другом компьютере

Нужен Python 3.12+. Ollama необязательна: backend, frontend, аналитика и MCP работают без неё. В папке проекта выполните:

```sh
python3 scripts/setup.py
```

Скрипт создаст `.venv`, установит зависимости из `requirements.lock`, создаст уникальные ключи в `.env` и `ACCESS.txt` и сформирует `claude-desktop-mcp.json`. Существующие настройки не перезаписываются. Новая установка по умолчанию не настраивает LLM. Модель скачивается отдельно; её веса, Python-окружение и Ollama не вложены в ZIP.

macOS/Linux:

```sh
.venv/bin/python scripts/laptop.py
```

На macOS также можно открыть `Start.command`. Windows:

```powershell
.venv\Scripts\python.exe scripts\laptop.py
```

Откройте http://127.0.0.1:8000 и введите ключ редактора из `ACCESS.txt`. Ключ просмотра предназначен для внешнего агента. Сервер и Ollama слушают localhost. По умолчанию скрипт не запускает и не вызывает Ollama, даже если в старом `.env` остались настройки модели. Опционально: `python3 scripts/setup.py --llama`, затем `.venv/bin/python scripts/laptop.py --with-ollama`. Если Ollama отсутствует, приложение продолжает запуск с автоматической аналитикой. Ctrl+C останавливает процессы, запущенные скриптом.

Для временного внешнего доступа (нужен SSH-клиент): добавьте `--public`. Используется Pinggy: адрес появится в терминале и `data/public-url.txt`. Бесплатный туннель действует 60 минут, новый запуск меняет адрес. Ноутбук должен работать и иметь интернет. Постоянный хостинг не настроен; Тильда не используется.

## Состав и данные

- `frontend/` — интерфейс, анимации, ассеты и API-клиент.
- `app/` — API, роли и доступ, снимки истории, источники, ассистент и MCP.
- `scripts/` — переносимая настройка, запуск и локальный MCP-мост.
- `tests/` — проверки API, версий, MCP, ассистента и API-клиента.
- `data/krok.db` — снимок текущей базы приложения на момент упаковки. История чатов в поставляемой копии очищена. Это ваши данные; не размещайте базу в публичном репозитории.
- `openapi.json` — актуальная схема API; живая схема также доступна на `/openapi.json`.
- `integrations/` — примеры подключения своего агента.

Личные ключи, `.env`, журналы сервера и история Git в архив не включены. Для запуска с чистыми демонстрационными данными укажите в `.env` другой новый путь `DATABASE_PATH`; при `SEED_DEMO=true` база будет заполнена демоданными. Не удаляйте рабочую базу для этого.

## Возможности

Клиенты, карта клиента/сделки/человека, карточки контактов, правки, источники, проверка и отклонение связей, реальные сохранённые версии и чат. Ползунок истории перемещает контакты и загружает соответствующий снимок. При одной версии он отключён. Доступ на изменение имеет только редактор.

Анимации: последовательное появление карточек и контактов, раскрытие колец, прорисовка подтверждённых связей, движение пунктира, переходы панелей, наведение и нажатие, индикатор ответа. Поддерживается `prefers-reduced-motion`.

Источники: текст или `.txt` до 100 000 символов. PDF/Word/аудио напрямую не поддерживаются. Извлечённые связи получают статус `proposed`; проверяются ID контактов и точность цитат. Изменения применяются атомарно. На старой версии карта доступна только для просмотра.

## Ассистент

Локальная `llama3.2:3b`, температура 0, контекст 8192, удержание модели в памяти 30 минут. Кнопки панели: сводка, сравнение версий, рекомендации и помощь. Эти функции используют SQLite без LLM и не изменяют карту. Сравнение показывает добавленные, удалённые и изменённые контакты, связи и сделки. Выберите снимок ползунком и исходную версию в диалоге, либо напишите «Сравни версии 1 и 3». Справка по интерфейсу хранится в `app/site_knowledge.py`; ответы на типовые вопросы выдаются сразу. Для вопросов о данных отбираются подходящие записи, модель выбирает факты, а итоговые значения выводятся из базы. Ассистент учитывает выбранную версию карты. Это подключение базы знаний, не дообучение весов модели. Ассистент может ошибиться в выборе фактов и не гарантирует ответ на произвольный вопрос. Он не управляет браузером и не изменяет данные.

В `.env` настраиваются `LLM_BASE_URL`, `LLM_MODEL`, `LLM_TIMEOUT` и при необходимости `LLM_API_KEY`. Для локальной Ollama: `http://127.0.0.1:11434/v1`. Без модели ответы обозначены «Автоматическая аналитика · данные SQLite, без LLM». При недоступности настроенной модели чат возвращается к автоматической аналитике; ожидание HTTP ограничено 20 секундами (подключение — 2 секунды). Для облачного OpenAI-совместимого провайдера нужна поддержка структурированного JSON-ответа.

## Собственный агент: GPT / Claude / MCP

Кнопка «Подключить своего агента» показывает адрес и инструкции для Codex, Claude
и Custom MCP. Проверка доступности выполняет настоящие `initialize` и `tools/list`
с ключом текущего пользователя. Она не утверждает, что внешний агент подключён.
Ответы внешнего агента остаются в его клиенте; приложение не вызывает платные API.

GPT через Codex MCP (macOS/Linux, из папки проекта, сервер уже запущен):

```sh
codex mcp add krok -- "$(pwd)/.venv/bin/python" "$(pwd)/scripts/mcp_stdio.py"
codex mcp list
```

Мост читает ключ **просмотра** из локального `.env`. На Windows укажите абсолютные
пути к `.venv\Scripts\python.exe` и `scripts\mcp_stdio.py`. Откройте новый чат
Codex и попросите вызвать `list_clients`, затем `get_client_context` для нужного
клиента. Ollama для этого не нужна. [Документация Codex MCP](https://learn.chatgpt.com/docs/extend/mcp).

Альтернатива — прямой HTTP, если `KROK_API_KEY` уже безопасно задана в окружении
процесса Codex (значение ключа не вставляйте в команду или репозиторий):

```sh
codex mcp add krok-http --url http://127.0.0.1:8000/mcp/ --bearer-token-env-var KROK_API_KEY
```

`localhost` доступен только на машине сервера. Для удалённого клиента нужен
доступный ему HTTPS-адрес и `PUBLIC_HOSTS`. У моста адрес переопределяется через
`KROK_MCP_URL`. Внешний клиент должен поддерживать Bearer или локальный stdio;
вход по OAuth не реализован. Не подменяйте проверку сервера заявлением о подключении агента.


MCP: `http://127.0.0.1:8000/mcp/`, Streamable HTTP, `Authorization: Bearer <ключ просмотра>`. Для внешнего подключения используйте действующий публичный URL сервера. Для Pinggy добавьте `X-Pinggy-No-Screen: true`. Допустимые внешние хосты задаются в `PUBLIC_HOSTS`; скрипт запуска делает это для созданного туннеля.

8 инструментов: `list_clients`, `get_client_map`, `get_contact`, `get_client_history`, `get_client_context`, `get_source`, `list_sources`, `get_site_help`. Только чтение, с проверкой доступных ключу клиентов. Исторический контекст поддерживает `version`. Внешний агент не видит текущий экран: передайте нужные `client_id`, `scope`, `scope_id`, `version`.

Claude Desktop: после setup объедините созданный `claude-desktop-mcp.json` с конфигурацией клиента. Мост `scripts/mcp_stdio.py` использует ключ просмотра из локального `.env`; ключ не нужно помещать в JSON. Claude Code и другие HTTP-клиенты могут подключаться напрямую с Bearer-заголовком. GPT-агент: пример `integrations/gpt-agent.py`; задайте собственные ключи и публичный URL. Облачные вызовы не настроены и не выполняются установкой. OAuth не реализован: нужен клиент с поддержкой Bearer или stdio.

## Проверка

```sh
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
node --test tests/api.test.mjs
```

При упаковке: 25 Python-тестов и 3 Node-теста прошли. Проверены синтаксис JavaScript и структура ZIP. Docker-файлы включены, контейнерный запуск в этой поставке не проверялся. Для Ollama на хосте из Docker нужен `LLM_BASE_URL=http://host.docker.internal:11434/v1`.

Используйте один Uvicorn worker. Это рабочий MVP с SQLite; SSO, полноценная CRM-интеграция, постоянный публичный домен и промышленная очередь заданий не настроены.

### Демонстрационная история

При `SEED_DEMO=true` и `SEED_HISTORY=true` (по умолчанию) новая база содержит
по 9 снимков для Краснодара, ВТБ и М.Видео: по 10 контактов, 2 сделки,
9 связей, 9 взаимодействий и 49 источников. Среди источников — 20 протоколов
и 20 писем из предоставленных тестовых материалов. Они являются данными,
а не инструкциями для приложения. Связи демосценария имеют отдельные
синтетические источники и точные цитаты; они не выводятся из чужих писем.
S7 остаётся примером пустой карты.

Нетронутые стартовые демокарты дополняются автоматически. Карты с пользовательскими
правками не меняются. Для полного сценария в отдельной базе установите
`DATABASE_PATH=data/demo-history.db`; существующую базу удалять не нужно.
`SEED_HISTORY=false` оставляет минимальный набор для API-проверок.

Ползунок загружает снимки при перетаскивании; стрелки переключают соседние версии,
▶ воспроизводит историю, Ⅱ ставит её на паузу. Под шкалой показаны версия,
изменение и время сохранения. Контакты и линии движутся вместе; при системной
настройке уменьшения движения переходы отключаются. Старые версии доступны
только для просмотра.

### Публичный MCP для жюри

URL: https://vvv3.onrender.com/mcp-demo/ — Streamable HTTP, No Authentication. Восемь инструментов только для чтения. Используется та же база и актуальные версии карты, что и в веб-интерфейсе. Публичный доступ ограничен четырьмя демонстрационными клиентами (krasnodar, vtb, mvideo, s7 с CRM ID demo-<id>), включая их источники и историю. Не загружайте конфиденциальные данные в эти демонстрационные карточки. Основной `/mcp/` и REST API по-прежнему требуют ключ.
