Подключение в ChatGPT

  1. Откройте ChatGPT в браузере. Перейдите в раздел Plugins (Плагины).
  2. Нажмите «+» → Add custom MCP server.
  3. Вставьте название и MCP URL сверху. Выберите No Authentication.
  4. Подтвердите предупреждение и создайте плагин. Установите его.
  5. В новом чате выберите плагин через @ и отправьте вопрос.
Открыть ChatGPT

Создание кастомного MCP доступно в веб-версии при наличии соответствующих прав и тарифа. Если пункт отсутствует на телефоне, воспользуйтесь компьютером или Claude.

Подключение в Claude

  1. Откройте Claude в браузере → Customize → Connectors.
  2. Нажмите Add → Custom → Web (или Add custom connector).
  3. Вставьте название и MCP URL. Нажмите Continue.
  4. Выберите No sign in, оставьте дополнительные поля пустыми, нажмите Add.
  5. В чате нажмите «+» → Connectors и включите карту.
Открыть Claude

На Free доступен один кастомный коннектор. Подключение в мобильном приложении — бета; если пункта нет, используйте веб-версию.
